
**작성 원칙 (Writing Principles)**

1.  **목적 중심 (Purpose-Driven)**: 모든 문서는 명확한 목적을 가지며, 독자가 해당 목적을 쉽게 달성할 수 있도록 구성합니다.
2.  **구조적 작성 (Structured Writing)**: `Markdown`의 제목, 목록, 코드 블록 등을 활용하여 정보를 체계적으로 구조화합니다.
3.  **최신성 유지 (Up-to-Date)**: 코드베이스의 변경사항이 발생하면, 관련된 모든 문서를 신속하게 업데이트하여 최신 상태를 유지합니다.
4.  **명확하고 간결한 표현 (Clarity and Brevity)**: 전문 용어 사용을 최소화하고, 누구나 이해하기 쉬운 명확하고 간결한 언어로 작성합니다.
5.  **일관성 (Consistency)**: 전체 문서에서 통일된 용어와 서식을 사용하여 일관성을 유지합니다.
6.  **항목별 버전 관리 (Item-level Versioning)**: 각 문서 내의 주요 섹션(항목)은 개별적으로 버전을 관리합니다. 예를 들어, `Progress.md`의 '개발 목표'와 '기능 구성'은 서로 다른 버전을 가질 수 있습니다. 내용에 중요한 변경이 있을 때마다 해당 항목의 버전(예: v1.0.0 -> v1.1.0)을 업데이트하여 변경 이력을 명확히 추적합니다.

# 자동 매매 서비스

*2024.10.15 : Crypto 변동성이 너무 높으며, 방향성도 인플레이션에 따른 단순 우상향 혹은 우하향이 아닌 너무 예측불가능함, 그래서 한번 진입시 포지션 보유기간이 상당히 길어짐.
              그래서 현재 개발 및 전략 재검토 진행중*

## 1. 개발 목표
- **Problem**: 기존 시장에는 조건식, 선물 거래, 머신러닝을 모두 통합한 자동 매매 프로그램이 부족합니다.
- **Idea**: 현물(SPOT)과 선물(Perp) 거래를 모두 지원하고, 단순 지표를 넘어 머신러닝 예측 모델을 기반으로 매매하는 프로그램을 개발합니다.
- **Solution**: Python 기반의 API 연동 자체 매매 프로그램을 구축합니다.

## 2. 주요 기능 및 구조
- **GUI**: `PySide6`를 사용한 데스크톱 애플리케이션.
- **Upbit 연동**: `REST API`를 통한 계좌/주문 관리 및 `WebSocket`을 통한 실시간 시세 수신 기능이 완전하게 구현되었습니다.
- **Binance 연동**: 향후 선물 거래 기능 확장을 위해 `function_binance.py`에 API 연동을 위한 기본 구조(플레이스홀더)가 마련되었습니다.
- **데이터 처리**: `ta` 라이브러리를 활용하여 100개 이상의 기술적 보조지표를 생성하는 강력한 피처 엔지니어링 엔진을 탑재했습니다.
- **머신러닝 예측**: **(신규)** 기술적 지표를 기반으로 매수/매도/관망을 예측하는 더미(Dummy) 예측 파이프라인이 구현되었습니다. 현재는 무작위 예측을 수행하지만, 실제 모델을 통합할 수 있는 전체 구조가 완성되었습니다.

## 3. 사용기술
- **언어/프레임워크**: Python, PySide6, Pytorch(예정)
- **라이브러리**: Pandas, NumPy, Scikit-learn, TA, websockets
- **개발 환경**: Pycharm, Github
- **연동 API**: Upbit API, Binance API(예정)
